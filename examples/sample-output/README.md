# Reproducible sample output

`sample-events.json` is a deterministic, public-safe fixture showing the normalized event contract without depending on a live network request. It intentionally uses documentation ranges and synthetic identifiers rather than asserting current real-world events.

To reproduce equivalent derivative formats, load the fixture into the static console or use the server export helpers to produce CSV/GeoJSON. Live-source demonstrations are tracked separately because current provider state changes over time.
