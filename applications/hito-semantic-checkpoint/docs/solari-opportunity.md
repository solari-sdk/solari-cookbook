# Where this could go with Solari

**Proposal and design hypothesis only. No additional capability here is shipped, measured, or endorsed by Solari.**

As disposable computers become more available, a useful infrastructure question may shift from keeping the machine alive to deciding which prior support remains legitimate, what is current, what must be observed again, what is unknown, what authority exists, and what evidence is missing. HITO explores this layer.

A continuity-aware sandbox could receive bounded historical project evidence while requiring machine-current facts to be re-observed. A safe handoff could carry work across disposable computers without importing old runtime assumptions as current truth.

Cross-primitive evidence is another possible direction: some questions belong to Sandbox execution, some to a visible Desktop, and some to Browser interaction. A future integration could distinguish those needs explicitly.

Semantic scheduling is a further proposal: unresolved evidence requirements might help select a necessary compute primitive. This application contains no scheduler, fork/merge/lease system, Desktop integration, Browser integration, or autonomous agent.

These ideas complement Solari's compute primitives. They make no market, moat, patent, universal-performance, or platform-endorsement claim.
