# wsp brand

The mark is a tilde, because in a shell the tilde is home and wsp is your home on whatever box it lands on: two circular arcs at one stroke weight, so it stays a geometric glyph and not a squiggle, and the lockup reads as a path, home then wsp. The three files here hold the paths in currentColor, the React module beside them renders the same paths inline, the favicon under public and the desktop icons under apps/desktop/build are rasterised from the mark, and the wordmark is drawn as paths with no font dependency.
