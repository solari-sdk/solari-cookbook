# Tasks

Tasks is a single list of everything your team has agreed to do this month. Each row
is one task, carrying an ID, a label, a title, a status and a priority.

Start with [how the list works](/concepts/how-the-list-works) if you have not used it
before, or go straight to the [how-to guides](/category/how-to-guides) for a specific
job.
