# Filter tasks by priority

To see only the tasks that matter most, narrow the list to one priority.

1. Select **Priority** in the toolbar, above the table.
2. In the list that opens, select **High**.

Every row in the table now shows the High priority, and a **Reset** button appears at
the end of the filter row. Select it to bring the other tasks back.
