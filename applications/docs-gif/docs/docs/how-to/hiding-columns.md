# Hide a column

Columns you do not need can be switched off from the View menu.

1. Select **View**, above the table on the right.
2. In the list that opens, select **Priority** to untick it.

The Priority column disappears and the table shows only Task, Title and Status.
Select **Priority** again in the same list to bring it back.
