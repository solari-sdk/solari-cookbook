# Delete a task

Deleting asks for confirmation first, and can be reversed straight afterwards.

1. Find the row you want to remove. **TASK-8782** is the first row in the list.
2. At the right-hand end of that row, select the **⋮** button.
3. Select **Delete**, the last item in the menu.
4. In the dialog that asks **Delete TASK-8782?**, select **Delete**.

The row disappears and a message reading **Deleted TASK-8782** appears above the
toolbar with an **Undo** link. Select **Undo** to put the task back at the top of
the list.
