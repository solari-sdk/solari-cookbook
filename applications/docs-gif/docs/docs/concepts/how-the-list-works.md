# How the task list works

A task carries two independent fields. **Status** tracks how far along the work is,
from backlog through to done or cancelled. **Priority** says how much it matters, and
does not change as the work progresses.

Because they are independent, neither one orders the list on its own. Sorting a column
reorders the rows you can currently see; filtering changes which rows exist to be
sorted. The counts beside each filter option are computed before the filter is applied,
so they tell you how large the result will be before you commit to it.
