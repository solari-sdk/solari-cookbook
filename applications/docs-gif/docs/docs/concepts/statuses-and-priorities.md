# Statuses and priorities

**Status** answers how far along a task is: backlog, todo, in progress, done or
cancelled. It is the field that changes most often, and the one most worth filtering on.

**Priority** answers how much a task matters: low, medium or high. It is set when the
task is written and rarely changes afterwards.

The two are deliberately independent. A high-priority task can sit in the backlog for
weeks, and a low-priority one can be done this afternoon. Neither field implies the
other, which is why the list lets you filter and sort on them separately rather than
combining them into a single score.
